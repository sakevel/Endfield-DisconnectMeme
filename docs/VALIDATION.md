# 测试与验证指南

本文档介绍 Endfield-DisconnectMeme（封禁演出模组）的自动化测试套件与功能验证方法。

---

## 自动化测试

项目包含 Native C++ 状态机测试与网络拦截模拟测试：

```powershell
ctest --test-dir build -C Release --output-on-failure
```

### 测试套件说明

- **StateTests (`tests/state_tests.cpp`)**：
  - 测试演出的状态机流转：`Idle`（就绪）→ `Blocking`（阻断中）→ `LoginDialog`（弹窗展示）→ `Restored`（恢复完成）。
  - 验证紧急取消按键与超时保护计时器的恢复分支。

- **HookTests (`tests/hook_tests.cpp`)**：
  - 模拟应用层 TCP 读写拦截逻辑，验证阻断期间数据丢弃与恢复后的正常通道放行。
  - 验证原生登录弹窗调用拦截与首次点击后的消费重置逻辑。

---

## 实机功能验证清单

在游戏内测试时，建议按以下流程验证：

1. **触发断线**：
   - 处于场景中时按下 `Ctrl+Shift+F9`，确认几秒后游戏正确返回登录界面。
2. **弹窗呈现**：
   - 在登录界面点击登录按钮，确认弹出自定义文案的提示弹窗。
   - 确认文案内容、换行与演出说明显示无误。
3. **恢复登录**：
   - 点击确认关闭弹窗后再次点击登录，确认可正常连接服务器并进入游戏。
4. **紧急取消**：
   - 触发演出后立即按 `Ctrl+Shift+F10`，确认通信即刻恢复且游戏不返回登录界面。
