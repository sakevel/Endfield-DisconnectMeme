# 断线与封禁演出 (Disconnect Meme)

用于游戏录屏与整活创作的本地断线及弹窗演出模组。可在游戏内一键模拟断线并返回登录界面，在登录页呈现自定义原生警告弹窗。

## 操作方式

- **触发演出**（默认 `Ctrl+Shift+F9`）：
  - 阻断当前会话连接，数秒后游戏提示断开并返回登录界面。
  - 回到登录界面后通信自动恢复；点击登录会弹出自定义的原生警告弹窗。
  - 确认关闭弹窗后再次点击登录即可正常进入游戏。
- **取消演出**（默认 `Ctrl+Shift+F10`）：
  - 立即解除通信阻断并恢复正常游玩。

## 配置选项

在「模组菜单 → 断线与封禁演出」中可自定义：

- **重连失败演出延迟**：从触发到断开连接的缓冲秒数（默认 3 秒）。
- **断网自动恢复秒数**：超时保护，防止长时间断开通信。
- **假封禁提示正文**：支持多行文本，可自由编辑弹窗提示内容。
- **显示演出说明**：在弹窗末尾附加「视频演出 · 非真实封禁」提示。
