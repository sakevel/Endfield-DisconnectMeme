# 封禁演出 / Endfield-DisconnectMeme

用于游戏录屏与整活创作的本地断线及弹窗演出模组。可在游戏内一键模拟断线并返回登录界面，在登录页呈现自定义原生弹窗效果。

---

## 使用方法

1. 正常启动游戏并进入游玩场景。
2. **触发演出**（默认 `Ctrl+Shift+F9`）：
   - 阻断当前游戏会话的应用层连接，数秒后游戏触发连接断开并返回登录页面。
3. **弹窗展示**：
   - 回到登录界面后通信会自动恢复。
   - 首次点击登录时会弹出游戏原生风格的警告提示窗，展示自定义的说明内容（如封禁理由与时间）。
   - 点击确认关闭弹窗后，再次点击登录即可正常登录游戏。
4. **紧急取消**（默认 `Ctrl+Shift+F10`）：
   - 立即解除通信阻断并取消当前演出状态。

---

## 配置选项

在「模组菜单 → 断线与封禁演出 → 模组配置」中可自定义各项设置：

- **快速结束重连**：开启后快速触发断开并返回登录，关闭则等待游戏自然超时。
- **重连失败演出延迟**：从触发到断开连接的缓冲秒数（默认 3 秒）。
- **断网自动恢复秒数**：最长安全超时时间，超时后强制恢复网络通信。
- **假封禁提示正文**：支持多行文本（使用 `\n` 换行），可自由编辑内容。
- **显示演出说明**：在弹窗末尾附加「视频演出 · 非真实封禁」提示。

## 构建与安装

### 构建

```powershell
.\tools\build.ps1
.\tools\package.ps1
```

构建产物位于 `build/package/Release/disconnect-meme`。

### 安装

退出游戏后，通过 ModLoader 的安装工具进行部署：

```powershell
..\Endfield-ModLoader\tools\install-mod.ps1 -ModPackage .\build\package\Release\disconnect-meme
```
